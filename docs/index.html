Quick start

          
Open Terminal in the Code project folder. Running ls there should show bin, examples, and native. Run the apples example with either interpreter. Both print 15.

          

            

              
Native Rust

              
The included executable runs on Apple silicon Macs without Python or Cargo.

              

                
>_macOS arm64

                
./bin/code-lang examples/apples.code

              

            

            

              
Python reference

              
The launcher uses Python 3.10 or newer. You can also invoke the module with python3 -m code_lang.

              

                
>_macOS / Linux

                
./code-lang examples/apples.code

              

            

          

          
To write a program, save a UTF-8 text file such as hello.code in the project folder, then run ./bin/code-lang hello.code. Try say "Hello!" as your first line.

          
If Terminal can’t find the command, run pwd to check your folder. To run the native interpreter on another platform, build it from source below.

          
Program errors show the filename and physical line number, including blank and comment lines. A failed program exits with status 1.

        


        

          
Build from source

          
With Rust and Cargo installed, run these commands from the project folder. Cargo uses the dependency versions in native/Cargo.lock.

          

            
>_Cargo

            
cargo build --release --locked --manifest-path native/Cargo.toml

          

          

            
>_Run the build

            
./native/target/release/code-lang examples/apples.code

          

          
On Windows, run .\native\target\release\code-lang.exe examples\apples.code after building. The included executable was built and tested on Apple silicon macOS.

        


        

          
Values and variables

          
Values can be integers, decimals, double-quoted text, true, false, or collections. A single character is text. Strings accept JSON-style escapes such as \n and \".

          
Declare a variable once with remember before you use it. Use set to change it later. Names are case-sensitive and can contain ASCII letters, digits, and underscores. The first character must be a letter or underscore.

          

            

              
SyntaxWhat it does

              
                
remember score as 0
remember 0 as score		Declare a new variable in either order.

                
set score to 10Replace a declared variable's value.

                
add 5 to score
score but 5 more		Add to the stored number. add one to score also works.

                
take 2 from score
score but x less		Subtract a number or the value of a numeric variable.

                
say score
what is score?		Print a value. Both forms accept collection lookups.

                
say on one line scorePrint a value without adding a line break. Line breaks already in the value are preserved.

                
how many score?Print a numeric variable.

                
note: this is a commentSkip a whole comment line.

              
            

          

          
For value-first declaration from another variable, write remember (source) as target. With a bare identifier before as, Code treats it as the new variable's name.

        


        

          
Comments

          
Use comment on one line: to skip a whole line. Put comment: and end of comment on their own lines to enclose a block of text. The first standalone end of comment closes the block. note: also works for single-line comments.

          
        


        

          
Interactive input

          
ask "Your name?" and remember as name prints the prompt on its own line, reads one response, and declares name as text.

          
Type your response in Terminal or use the Answer field that appears in the browser playground. A blank answer is valid. Try ask.code.

        


        

          
Conditions and loops

          
    
            
  • if ready: runs a block when the condition is true. Add otherwise: for the false branch. One ok closes both branches.
    • 
            
  • while ready: checks the condition before each iteration. It can run indefinitely if the condition stays true.
    • 
            
  • do this 5 times: runs a block a fixed number of times. Code reads the count once, before the loop starts. It must be a non-negative integer.
    • 
          

          
Use a truth value or compare two values with is equal to, is not equal to, is greater than, or is less than. Ordering requires numbers. Equality accepts numbers, text, and truth values. 2 equals 2.0, and true is distinct from 1.

          
if answer is "Y": is short for if answer is equal to "Y":. Text comparisons are case-sensitive.

          
Close each loop with ok. Blocks can be nested. Indentation is for readability.

          
          

            

              
Turnip Complete!

              
In Code, Turnip Complete means Turing-complete. With unbounded memory, while loops, zero tests, and integer updates can simulate a universal two-counter machine.

            

            
          

        


        

          
Collections

          
A collection stores values in order. Positions start at 1. An item can also have a name that is unique within its collection. Item names are identifiers such as quantity.

          
Write a single-line collection as all of these: 1, 2, 3. For a multiline collection, put each item on its own line, optionally followed by a comma, and close with ok. A multiline collection with no items is empty.

          

            

              
SyntaxWhat it does

              
                
the first of inventory
position 11 of inventory		Read by position. Use first through tenth or a literal integer after position.

                
inventory named quantityRead a named item. Missing names and positions raise errors.

                
how many are in inventory?Print the number of items.

                
put "orange" into inventoryAppend an unnamed item.

                
put 20 into inventory named quantityReplace an existing named item at its current position.

                
remove the third of inventoryRemove the item and its name. Later positions shift down.

                
for each item in inventory:Visit every value in order. Close the loop with ok.

              
            

          

          
          
A for each variable is temporary. If it shadows a variable, the previous value returns when the loop exits. The collection being traversed cannot be resized, even through another variable that refers to it. You can replace a named item, and a later iteration will see the new value.

        


        

          
Nested collections

          
Wrap an inline nested literal in parentheses. In a multiline collection, a nested block can have its own ok followed by an optional name. Group a named lookup used as an item value, so Code can distinguish the lookup from a label on the new item.

          
          
Named lookups can chain, as in pantry named grains named breakfast. In the first of pantry named fruit, the position is inside fruit. Use (the first of pantry) named kind to read a name inside the positional result.

          
A put target ending in an ungrouped named updates that entry. Group the lookup to append to the collection it returns. Assigning or inserting a collection shares it by reference. Printed circular references appear as <cycle>.

The snake rule

          
A run of exactly seven consecutive § characters inside a quoted string becomes one 🐍. String escapes count after decoding. Separate runs of seven each become a snake.

          
          
A shorter or longer run, or any § outside a string, stops the program before any instructions run. This includes comments. The message is We must never speak of §!

Tests and limits

          
Run the shared tests against each interpreter, then run the Rust runtime tests. The shared test harness uses Python.

          

            
>_Terminal

            
python3 -m unittest discover -s tests -v
CODE_LANG_TEST_BINARY=./bin/code-lang python3 -m unittest discover -s tests -v
cargo test --locked --manifest-path native/Cargo.toml

          

          
Set CODE_LANG_TEST_BINARY to your own binary path if you built from source.

          
    
            
  • Arithmetic is limited to update commands. Decimal calculations use Python's floating-point precision.
    • 
            
  • Comparisons are available in conditions. General expressions and user-defined functions are outside v0.2.
    • 
            
  • Text literals occupy a single source line. The interpreter checks the syntax of every code block, including branches that never run.
    • 
            
  • The native interpreter limits parser nesting and printed collection depth to 128 levels.
    •
